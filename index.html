Slider.js

A lightweight and customizable slider library built with pure JavaScript.

1

Try It Out

Slider.js is a lightweight carousel/slider library built with pure JavaScript ES6+. (Source code available on GitHub)

  • No dependencies (Pure Vanilla JS)
  • Supports infinite loop with smart DOM cloning
  • Configurable multi-item display & slide-by-page
  • Autoplay support with pause-on-hover
  • Custom navigation buttons & pagination dots
